پرداخت امن سفارش‌های ووکامرس با تتر (USDT) از طریق درگاه رمزپال؛ همراه با Verify سمت سرور، Checkout Blocks و HPOS.

== Description ==

این افزونه درگاه پرداخت رمزپال را به ووکامرس اضافه می‌کند. مشتری پس از ثبت سفارش به صفحه امن پرداخت USDT هدایت می‌شود و سفارش فقط بعد از تأیید مستقل مبلغ، شناسه‌ها و وضعیت VERIFIED از API رمزپال تکمیل خواهد شد.

امکانات اصلی:

* پرداخت USDT روی شبکه BEP20
* پشتیبانی از Checkout کلاسیک و Blocks
* سازگاری با HPOS
* تبدیل مبلغ با نرخ ثابت برای واحدهای غیر USDT
* رابط و راهنمای فارسی
* زبان پرداخت فارسی، انگلیسی یا عربی
* لاگ امن و اختیاری برای عیب‌یابی

API رمزپال فقط مبلغ ۱ تا ۵۰۰۰ USDT را می‌پذیرد. اگر واحد فروشگاه USDT یا USD نیست، نرخ هر تتر را در تنظیمات درگاه وارد کنید.

== Installation ==

1. فایل ZIP افزونه را از پیشخوان وردپرس بارگذاری و فعال کنید.
2. به «ووکامرس ← پیکربندی ← پرداخت‌ها ← رمزپال» بروید.
3. وارد پنل رمزپال شوید، یک پذیرنده بسازید و API Key آن را از بخش مدیریت پذیرنده‌ها کپی کنید.
4. API Key را بدون کلمه Bearer در فیلد «کلید API» وارد کنید.
5. روش محاسبه مبلغ را انتخاب و درگاه را فعال کنید.
6. یک خرید کم‌مبلغ را از ابتدا تا صفحه سفارش موفق آزمایش کنید.

== Frequently Asked Questions ==

= کلید API را از کجا دریافت کنم؟ =

پس از ورود به پنل رمزپال، کلید مخصوص مرچنت در بخش مدیریت پذیرنده‌ها در دسترس است.

این کلید همان توکن احراز هویت Bearer است. فقط خود API Key را در تنظیمات وارد کنید؛ افزونه عبارت Bearer را خودکار اضافه می‌کند. اگر هنوز پذیرنده ندارید، ابتدا از نشانی https://ramzpal.com/profile/merchant/create یک پذیرنده بسازید.

= لازم است Callback را در جایی ثبت کنم؟ =

خیر. افزونه برای هر سفارش آدرس Callback امن را می‌سازد و همراه درخواست پرداخت ارسال می‌کند.

= فروشگاه من تومان یا ریال است؛ آیا افزونه کار می‌کند؟ =

بله. حالت «تبدیل با نرخ ثابت» را انتخاب و قیمت یک USDT را بر حسب واحد فعال فروشگاه وارد کنید. نرخ باید توسط مدیر فروشگاه به‌روز نگه داشته شود.

= چرا درگاه در تسویه‌حساب دیده نمی‌شود؟ =

فعال بودن درگاه، وجود کلید API و تنظیم درست واحد پول/نرخ تبدیل را بررسی کنید. مبلغ نهایی نیز باید بین ۱ تا ۵۰۰۰ USDT باشد.

= لاگ‌ها کجا هستند؟ =

پس از فعال کردن گزارش فنی، در «ووکامرس ← وضعیت ← گزارش‌ها» منبع ramzpal را انتخاب کنید.
