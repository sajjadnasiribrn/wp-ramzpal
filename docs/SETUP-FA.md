# راه‌اندازی سریع درگاه رمزپال در ووکامرس

این راهنما برای مدیر فروشگاه نوشته شده و دانستن برنامه‌نویسی لازم نیست.

## ۱. دریافت API Key

1. وارد [حساب رمزپال](https://ramzpal.com/login) شوید.
2. اگر هنوز پذیرنده ندارید، از [صفحه ساخت پذیرنده](https://ramzpal.com/profile/merchant/create) یک پذیرنده برای دامنه فروشگاه بسازید.
3. در پنل، بخش مدیریت پذیرنده‌ها را باز کنید.
4. پذیرنده فروشگاه را انتخاب و مقدار **API Key** را کپی کنید.

فقط خود API Key را کپی کنید و چیزی قبل یا بعد از آن ننویسید. افزونه بقیه کارها را انجام می‌دهد.

API Key را محرمانه نگه دارید. آن را برای مشتری نفرستید و در فایل عمومی، اسکرین‌شات یا تیکت عمومی قرار ندهید.

## ۲. نصب افزونه

1. در پیشخوان وردپرس وارد «افزونه‌ها ← افزودن افزونه تازه» شوید.
2. «بارگذاری افزونه» را بزنید و ZIP افزونه را انتخاب کنید.
3. «هم‌اکنون نصب نمایید» و سپس «فعال کردن افزونه» را بزنید.
4. وارد «ووکامرس ← پیکربندی ← پرداخت‌ها ← رمزپال» شوید.

## ۳. تنظیم درگاه

1. API Key را در فیلد «کلید API» قرار دهید.
2. اگر قیمت‌های فروشگاه USDT یا USD هستند، محاسبه مبلغ را روی «یک‌به‌یک» بگذارید.
3. اگر فروشگاه تومان، ریال یا واحد دیگری دارد، «تبدیل با نرخ ثابت» را انتخاب کنید و قیمت یک تتر را بر اساس همان واحد وارد کنید.
4. زبان صفحه پرداخت و پیام‌های موفق/ناموفق را انتخاب کنید.
5. درگاه را فعال و تنظیمات را ذخیره کنید.

نرخ ثابت خودکار تغییر نمی‌کند؛ پس هر زمان لازم بود آن را به‌روز کنید. مبلغ نهایی پرداخت باید بین ۱ تا ۵۰۰۰ تتر باشد.

## ۴. آزمایش قبل از انتشار

1. فروشگاه را موقتاً در حالت staging یا تعمیر قرار دهید.
2. یک محصول با مبلغ نهایی کم، اما حداقل ۱ USDT بسازید.
3. خرید را مثل یک مشتری تا صفحه رمزپال ادامه دهید.
4. پرداخت را کامل کنید و مطمئن شوید به صفحه سفارش موفق برمی‌گردید.
5. در مدیریت سفارش مطمئن شوید وضعیت پرداخت تکمیل شده و شناسه پرداخت در یادداشت سفارش دیده می‌شود.

رمزپال محیط آزمایشی جداگانه‌ای در مستندات فعلی معرفی نکرده است؛ بنابراین تست نهایی باید با یک پرداخت واقعی کم‌مبلغ انجام شود.

## ۵. اگر درگاه نمایش داده نشد

- فعال بودن ووکامرس و خود درگاه را بررسی کنید.
- مطمئن شوید API Key خالی نیست.
- اگر حالت یک‌به‌یک انتخاب شده، واحد فروشگاه باید USDT یا USD باشد.
- در حالت تبدیل ثابت، قیمت هر USDT باید بزرگ‌تر از صفر باشد.
- مبلغ تبدیل‌شده باید بین ۱ تا ۵۰۰۰ USDT باشد.

## ۶. اگر پرداخت تأیید نشد

- یادداشت‌های همان سفارش را بررسی کنید.
- گزارش فنی را موقتاً فعال و از «ووکامرس ← وضعیت ← گزارش‌ها» منبع `ramzpal` را باز کنید.
- اعتبار API Key و دسترسی خروجی HTTPS هاست به `ramzpal.com` را بررسی کنید.
- مطمئن شوید فایروال، CDN یا افزونه امنیتی، آدرس بازگشت ووکامرس را مسدود یا ذخیره موقت نمی‌کند.
- وضعیت پرداخت را با `payment_id` در پنل رمزپال بررسی کنید.

پس از رفع مشکل، گزارش فنی را غیرفعال کنید.
